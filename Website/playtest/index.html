Before you play

This is an early test version. While you play, the game sends what you do in the game (for example "levelled up a Minion", "lost to a boss") with the time, together with your tester code , to the developers.

It also sends the game version and a random ID made by the game, so we can tell two of your devices apart. It doesn't send your name, e-mail, location or anything else about you or your device. The data is only used to improve the game and is deleted after the playtest.
